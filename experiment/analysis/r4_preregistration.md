## 0. 种子与共同口径

- 种子沿用 20261017(`SEED`)体系:A 用 `SEED+41`,B 用 `SEED+42`,J 用 `SEED+43`,K 用 `SEED+44`,I(外部数据重抽)用 `SEED+45`;C/D 重跑 r3_c 时沿用 `SEED+5`,以便逐值复现 r3 的 `R5_cross_pathogen`。并行时每格的随机流由 `numpy.random.SeedSequence([种子, 组合序号, 格序号])` 派生,结果与进程数无关。
- 拟合管线与实证完全相同:三种滞后权重 original (0.65, 0.25, 0.10)、single_1w (1, 0, 0)、equal_3w (1/3, 1/3, 1/3);保留 D_t ≥ 5;G_t = C_{t+1}/D_t;R̄ 为样本均值;L = ((G − R̄)/R̄)²;迭代 FGLS 拟合 L = a + b/D;q1 = a_single/a_orig,q2 = a_equal/a_orig。
- 七个病原—窗口组合与 r3_c 相同:流感 W-cal、W-growth、W-growth-2025;COVID-19 W-cal、W-growth;RSV W-cal、W-growth。

## 1. 生成模型(A、B、J、K 共用)

日分辨率更新过程。I_d ~ Poisson(Gamma(形状 kΛ̃_d,尺度 R_d/k)),Λ̃_d = Σ_s g_s I_{d−s},即均值 R_d Λ̃_d、离散参数 kΛ̃_d,k = 0.35。报告:每日 Bin(I_d, ρ·p_w),ρ = 0.021;可选入院延迟(离散 gamma,把每日报告数多项分配到之后各日);按日历周汇总为 C_w。世代间隔用序列间隔近似(文献只给出序列间隔,这是标准近似,写入局限)。

段结构按组合匹配实证:在各州按该组合选窗规则(不加 D 过滤)取连续入选周段,段长与实证相同;段首规模取实证段首周 D_t(小于 1 取 1);每段前置 3 周预热、后加 1 周前瞻;历史期按目标增长率指数增长初始化。

增长率校准:常增长下 G = λ/(0.65 + 0.25/λ + 0.10/λ²),由目标 R̄ 反解周增长因子 λ,日增长率 r = ln λ/7,R0 = 1/Σ g_s e^{−rs}(Euler–Lotka)。每个组合 × 世代间隔先跑 100 次试点(环境 CV² = 0.0287、无延迟),按 目标²/试点均值 一次性修正目标 R̄ 再反解 λ;修正量与各格实际模拟 R̄ 一并报告。

## 2. A:各病原增长期 φ = 0 零假设

- 环境噪声:R 在一个日历周内恒定,周间独立(φ = 0),R_w = max(0.05, R0(1 + ε_w)),ε_w ~ N(0, CV²)。CV² ∈ {0.0036, 0.0143, 0.0287, 0.0574},后三档等于 r3 情景 v_R ∈ {0.04, 0.08, 0.16} 在 R̄ = 1.67 下的相对方差,第一档(v_R = 0.01 当量)覆盖 COVID-19 的低截距。
- 增长网格:目标 R̄ ∈ {下端, 点估计, 上端},下端 = min(r3 BCa 下端, 0.97 × 点估计),上端 = max(r3 BCa 上端, 1.03 × 点估计)。
- 世代间隔(均值/标准差,天;来源见第 11 节):
  - 流感:短 2.2/0.98、中 3.6/1.6、长 4.3/1.91(Cowling 2009 均值 3.6、95% CI 2.9–4.3、SD 1.6;短档取 Vink 2014 H3N2 合并估计 2.2;短、长两档 CV 与中档相同)。
  - COVID-19:短 2.3/1.5、中 3.2/2.08、长 3.9/2.54(Madewell 2023 Omicron 合并 3.2,BA.5 2.3,Delta 3.9;CV 0.65 为假设)。
  - RSV:短 6.0/1.68、中 7.5/2.1、长 9.0/2.52(Vink 2014 RSV 7.5、SD 2.1 来自单一数据集;±20% 为敏感性假设)。
- 入院延迟:无;短(gamma 均值 4 天、SD 2);长(均值 7 天、SD 3.5)。延迟分布是敏感性假设,不是文献估计;均值本身不影响结果,起作用的是延迟的离散度对周计数的平滑。
- 每格 300 次。格数 3 增长 × 4 CV² × 3 世代间隔 × 3 延迟 = 108 格/组合。
- 零假设范围:格点**均值**的 [最小, 最大]。报告三种范围:无延迟带(与 r3 每周一代模型可比)、全部延迟带、全部格。主分级用全部格。

## 3. B:M-mult 增长期

v_R = 0;报告率乘性噪声 p_w = exp(x_w − σ²/2),x_w 为平稳 AR(1),系数 ψ ∈ {0, 0.3, 0.6, 0.9},σ² = ln(1 + τ²),τ ∈ {0.15, 0.3};世代间隔中档;延迟 {无, 长};增长网格同 A。3 × 4 × 2 × 2 = 48 格/组合,每格 300 次。范围取格点均值的 [最小, 最大]。

## 4. C:三词重新分级(r4_adoption 第 0 节)

- 先以 `SEED+5`、B = 2000 重跑 r3_c 的州聚类重抽,保存全部抽样(`analysis/r4_boot_draws.npz`),核对与 r3 `R5_cross_pathogen` 的点估计和 BCa 端点一致(容差 1e-9;不一致则停下记录原因)。
- 零假设集合 = 本病原 A 全部格均值范围 ∪ B 全部格均值范围,取凸包(截距可加,混合机制下截距比是两者的加权平均,落在两端之间)。
- E_ratio:q1 与 q2 的 95% BCa 区间都与该范围不相交(CI 反演,不用模拟分位数加宽);E_excess:超出量 a − 0.08/R̄² 的 BCa 下端 > 0。复现 = 二者都满足;部分复现 = 恰一项;方向一致 = 都不满足但 q1 BCa 上端 < 1 < q2 BCa 下端;其余为未复现。
- 如实计数。另报两套对照分级:只用 A 无延迟带 ∪ B 无延迟格(与 r3 口径最接近),以及 r3 的流感增长带。不因结果调整判据或网格。

## 5. D:TOST 等价检验(可观测报告贡献 Δa = a − a*)

- 主 margin:δ = 0.05 × a(该组合截距点估计);次 margin:δ' = 0.05 × 超出量点估计,只对超出量点估计 > 0 的组合计算(超出量为负时无定义)。
- 两个单侧检验 H01: Δa ≤ −δ,H02: Δa ≥ δ,用重抽标准差作正态近似,p1 = 1 − Φ((Δa + δ)/se),p2 = Φ((Δa − δ)/se);等价 ⇔ max(p1, p2) < 0.05。并列报告 90% 百分位区间与 90% BCa 区间,以“90% 区间落在 (−δ, δ) 内”作为区间判定;两种判定不一致时如实写出。

## 9. J:报告离散度 τ 网格(Δa 判据的水平与功效)

- 结构:流感 W-cal 段,世代间隔中档、无延迟、φ = 0、CV² = 0.0287、R̄ 点估计。
- 报告率 = ρ · h_w^κ · u_w。h_w 为该段对应州周的实证填报医院比例(NHSN `Percent Hospitals Reporting Influenza`,缺失或 0 取 1);u_w 为不可观测乘性噪声,对数正态,CV = τ,周间独立。τ ∈ {0, 0.05, 0.1, 0.15, 0.2, 0.3, 0.5};κ ∈ {0(调整只加噪声,判据水平), 1(实证强度), 3, 5, 8(功效)}。
- 每次模拟:算未调整与按 h 调整的 a、a*,Δa = a − a*;州聚类 B = 200 重抽 + jackknife,BCa 95%;按 r3 判据 D1(Δa BCa 下端 > 0 且点估计 ≥ 0.02)/ D2(上界 max(BCa 上端, 0))。
- 每格 200 次。报告:D1 比例(κ = 0 为水平,κ ≥ 1 为功效);D2 上界 / 超出量(超出量 = a − 0.08/R̄²)< 1% 的比例与中位数;D2 上界 / a 的中位数。
