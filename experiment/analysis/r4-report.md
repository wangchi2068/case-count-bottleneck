日期:2026-10-18。范围:不新增命题,只补实证与仿真。所有数字取自 `analysis/r4_results.json`(下文用“键:路径”标注),
表 2 实证区间取自 `analysis/reanalysis_results.json` 的 `B_bootstrap`,跨病原点估计与区间取自 `analysis/r3_results.json` 的 `R5_cross_pathogen`。
判据、网格与种子都在 `analysis/r4_preregistration.md` 里事先写定(07:35 UTC,早于 A–K 的主运行);事后加的分析都标了“事后”。本轮没有调用任何 LLM API。

## 0. 结论摘要

1. **重新分级(C)**:按预注册主口径,7 个病原—窗口组合中复现 0 个、部分复现 4 个、方向一致 3 个、未复现 0 个,远低于此前“5/7”的说法。4 个部分复现都是因为超出量 a − 0.08/R̄² 的 BCa 下端 > 0,也就是流感三个组合和 RSV W-cal;截距比这条判据在 7 个组合里一个都没有通过。
2. **识别问题(A)**:日分辨率更新过程叠加入院延迟后,即使 φ = 0 也能产生 q1 < 1 < q2 的截距比特征。因此**截距比特征不能用来诊断 R 的自相关**,能当证据的只剩截距超出量。
3. **TOST(D)**:可观测报告贡献 Δa 在流感三组合上,三种判定都等价于 0(margin = 5% × a);7 个组合中按主判定(90% BCa)等价的有 5 个。
4. **τ 网格(J)**:Δa 判据只看得见与填报比例 h 相关的报告成分;与 h 无关的报告离散会抬高 a,Δa 却仍约为 0。摘要里“报告成分 < 1%”这句话需要收窄。
5. **复现包(H)**:`code/README.md` 与 `code/run_all.sh` 已写好。在干净目录里重跑表 2 和图 12 的全部数据,并逐值比较,结果见第 H 节。数字地图覆盖论文中的 1638 个数字,其中 1550 个已映射到结果键。

## A. 各病原增长期 φ = 0 零假设(日分辨率更新过程)

**方法。** 每个组合 108 格:3 档增长 × 4 档 CV² × 3 档世代间隔 × 3 档入院延迟,每格 300 次,种子 SEED+41。拟合管线与实证相同。零假设带取格点均值的 [最小, 最大],分三种:无延迟格、全部延迟格、全部格。

**结果**(键:`A_growth_null.bands`;流感 W-cal 见 `G_table2.columns`):

| 流感 W-cal | q1 | q2 |
|---|---|---|
| 实证点估计(95% 百分位区间) | 0.688(0.658–0.727) | 1.539(1.420–1.656) |
| 日更新、无延迟 | 0.746–0.887(与实证不相交) | 1.319–1.484(相交) |
| 日更新、全部格 | 0.601–0.887 | 1.187–1.568 |

长延迟格在 φ = 0 时给出 q1 ≈ 0.72、q2 ≈ 1.52(键:`A_growth_null.cells`),落在实证区间内。也就是说,只要每日报告数被入院延迟平滑,截距比特征就会出现,并不需要 R 有周间自相关。
事后统计(键:`C_posthoc.joint_A_cells`):φ = 0 时 a、q1、q2 三者同时落入实证 95% BCa 区间的格数为:流感 W-cal 5/108、流感 W-growth 0/108、流感 W-growth-2025 3/108、COVID-19 W-cal 11/108、COVID-19 W-growth 11/108、RSV W-cal 0/108、RSV W-growth 18/108。

**建议措辞与位置**(4.5 节末加一句,并在附录仿真中加一段):“日分辨率更新过程加入院延迟在 φ = 0 下即可产生 q1 < 1 < q2 的截距比特征,故该特征与 R 的周间自相关不可区分;本文以截距超出量作为主要证据。”

## B. M-mult 增长期

**方法。** v_R = 0,报告率乘性 AR(1) 噪声:ψ 取 4 档,τ 取 {0.15, 0.3},延迟取 {无, 长};每组合 48 格,每格 300 次,种子 SEED+42。

**结果**(键:`B_mmult_growth.bands`):流感 W-cal 的 q1 为 0.686–1.224,q2 为 0.865–1.497(`G_table2.columns`)。这个带与实证 q1 区间相交,与 q2 区间也相交,所以只靠报告率噪声同样不能排除截距比特征。

**位置**:表 2 新增“M-mult 增长期”一列。

## J. τ 网格:Δa 判据的检验水平与功效

键:`J_tau_grid_dA_criterion`。

- **检验水平**:κ = 0 时 D1 拒绝率在全部 35 格中都是 0(`level_max_D1_rate_kappa0`)。
- **功效**:D1 的功效同样为 0,即使 κ = 8,Δa 也不超过 0.0033。原因是实证 h 变化很小(`h_summary`):中位数 0.943,h < 1 的州·周占 0.843,h < 1 部分的 10% 分位数为 0.818。
- **随 κ 的变化**:BCa 下端 > 0 的比例在 κ = 3、5、8 时分别为 0.06–0.47、0.23–0.86、0.45–0.95;各格“上端/超出量”的中位数在 κ = 1 时为 0.0054–0.0118,κ = 8 时为 0.016–0.063。按格中位数,“< 1%”在全部格中并不都成立(`lt1pct_holds_all_cells_median` = False)。
- **与 h 无关的报告噪声**:τ 从 0 增到 0.5 时 a 从 0.10 升到 0.52,Δa 却仍约为 0。Δa 对这类噪声是盲的。
- **实证**:上端 0.00065 / 超出量 0.0704 ≈ 0.93%,与 κ ≲ 1 相容。

**建议措辞**(摘要与 4.4 节):把“报告成分不足 1%”改为“可由填报比例观测到的报告成分不足超出量的 1%;与填报比例无关的报告离散不受此约束”。
