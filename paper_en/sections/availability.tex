\section*{Data and code availability}
\label{sec:availability}

The NHSN Weekly Hospital Respiratory Data are publicly available from the U.S. Centers for Disease Control and Prevention \citep{cdc2026nhsn}; the analyses used the version retrieved on 2026-10-20. The code for the simulations, estimation and figures is available at \url{https://github.com/wangchi2068/case-count-bottleneck}.
